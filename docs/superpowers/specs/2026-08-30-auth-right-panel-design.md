# 认证右侧表单区优化设计

## 目标

将登录、注册、忘记密码和重置密码页面右侧的表单区从“嵌套卡片”调整为完整的安静画布（方案 B）。右侧成为清晰、连续的操作表面，减少重复边框和阴影，让用户注意力集中在标题、字段和主操作上，同时保留当前认证行为、路由和国际化。

## 方案

- 右侧认证区域继续使用现有 `data-auth-region="form"` 容器和响应式宽度。
- 认证表单卡片提供 `flat`/画布变体：透明背景、无外边框、无外层阴影，保留内容最大宽度和内边距。
- 登录和注册的 tabs 从实心分段按钮改为底部细线导航：当前项使用主题色下划线，非当前项使用弱化文字；仍然是可访问的真实路由链接。
- 表单标题和说明保持现有 i18n 文案，使用更明确的层级和更宽松的上下节奏。
- 输入框保留稳定高度、圆角和焦点环；主按钮保留主题色、图标、悬停/按下状态和完整宽度。
- 忘记密码和重置密码复用同一画布变体，不改变验证码、邮件、token、提交、成功和错误行为。
- 右侧顶部增加轻量品牌/安全状态行只作为视觉层级，不新增业务状态或网络请求；若现有组件没有可复用的安全状态数据，则使用静态、非承诺性标签或不显示。
- 移动端继续使用现有单栏结构；画布样式不得引入横向滚动或额外视频加载。

## 非目标

- 不修改认证 API、校验规则、提交逻辑、OAuth、Passkey、验证码或权限行为。
- 不改变左侧视频、标题轮播、品牌叙事区和认证路由结构。
- 不新增 UI 依赖，不改动全局主题变量。

## 验收标准

1. 四个认证页面均使用安静画布右侧样式，页面中不再出现右侧表单的重复卡片边框/阴影。
2. 登录/注册 tabs 仍可通过键盘和点击导航，当前项有清晰主题色指示。
3. 表单字段、错误提示、提交按钮和辅助链接保持可见、可操作且不溢出；320px 视口无横向滚动。
4. 所有现有认证行为和多语言文案保持不变。
5. 相关组件测试、typecheck、lint、format 和生产构建通过，并补充画布变体和 tabs 状态的回归断言。
