# 认证路由切换动效与欢迎语层级设计

## 目标

让登录、注册、忘记密码和重置密码之间的切换具有明确但克制的过渡反馈，同时放大登录页右侧欢迎语、填补标题上方的视觉空白。动效不应重置左侧背景视频或按钮画布，也不改变认证业务行为。

## 方案

- 在 `AuthExperienceLayout` 的右侧表单内容槽增加稳定的内容包裹层，路由页面重新挂载时仅对该层执行一次淡入和轻微上移。
- 使用 `opacity` 与 `transform: translateY(...)`，持续约 360ms，采用 `cubic-bezier(0.22, 1, 0.36, 1)` 的自然减速曲线；不动画化宽高、边距或定位，避免布局抖动。
- 左侧品牌区、视频、点阵背景、外层认证面板保持稳定，不因路由切换而重新播放或缩放。
- 登录页 `Welcome back! 👋` 标题提升到约 24px，并增加标题区上下节奏；其它页面标题复用同一标题层级，保证长译文可以换行且不溢出。
- 认证 tabs 和忘记密码入口继续使用真实路由链接，动画不阻塞点击、键盘导航或表单提交。
- 在 `prefers-reduced-motion: reduce` 下取消位移和过渡，内容直接以最终状态显示；已有背景视频和标题轮播的降级逻辑保持不变。

## 非目标

- 不修改认证路由、API、表单校验、OAuth、Passkey、验证码或密码重置流程。
- 不引入新的动画运行时依赖，不重播背景视频，不为每个字段增加独立动画。
- 不改变左侧叙事标题轮播、模型连接线或动态提交按钮的既有行为。

## 验收标准

1. 从登录切换到注册、从登录进入忘记密码，以及重置密码页面加载时，右侧表单内容均有一次可见的淡入上移动效。
2. 动效只作用于右侧表单内容；左侧视频/背景不会闪烁、重新加载或改变位置。
3. 登录页欢迎语在桌面和移动视口都比当前更醒目，中文、英文及长译文不裁切、不产生横向滚动。
4. `prefers-reduced-motion: reduce` 下右侧内容无动画且仍然可见，所有链接和表单操作保持可用。
5. 相关认证布局测试覆盖动效标记和标题尺寸层级；typecheck、lint、format、生产构建通过。
