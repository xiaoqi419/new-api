# 登录页竖向动态词位设计

## 背景

登录页左侧叙事标题目前使用固定的两行默认文案。为了让首屏更有识别度，同时保持产品工具属性和登录操作的稳定性，标题最后一个词需要增加从下向上进入、停留、向上退出的竖向轮播效果。

## 目标

- 默认标题保留“为开发者打造，为规模而”的语义骨架。
- 最后一行在“设计、构建、集成、扩展、编排”之间循环切换。
- 词语从固定高度的裁剪窗口下方进入，停留后向上离开。
- 动效只使用 `transform` 与 `opacity`，不改变标题布局尺寸。
- 不新增运行时依赖；使用组件内 CSS keyframes，避免登录首屏引入额外动画包。
- 动效与现有本地 Iconsax 背景视频、模型连接高光保持层次关系，不遮挡品牌、说明文字或模型提示。

## 范围与非目标

范围仅限 `AuthExperienceLayout` 的默认登录叙事标题、对应 i18n 文案、布局测试和 changelog。后台配置的自定义标题、认证流程、视频加载策略、注册/找回密码页面均不改变。

## 交互与视觉方案

默认标题拆成三段：

```text
为开发者打造，
为规模而
设计
```

“设计”所在区域使用 `overflow: hidden` 和固定行高。每个词使用相同的 CSS 动画延迟依次显示：从 `translateY(110%)` 和透明状态进入，短暂停留，再移动到 `translateY(-110%)` 并淡出。动画持续时间保持在首屏叙事可感知但不拖沓的范围内，使用平滑减速曲线，不使用 bounce 或 elastic easing。

词位设定稳定的最小宽度和高度，避免中文词切换造成横向位移或标题跳动。词语使用当前主题色，固定前缀沿用现有白色标题样式。

## 响应式与无障碍

- 动态标题只在默认标题分支启用；`config.title` 有值时完整显示配置标题，不拆分、不轮播。
- 登录页移动端继续使用现有布局；品牌叙事区隐藏时不挂载动态词位。
- `prefers-reduced-motion: reduce` 下只保留静态“设计”，不执行 keyframes。
- 动态词列表对屏幕阅读器隐藏，提供一个等价的静态标题文本，避免重复朗读或在词语切换时反复播报。
- 动画元素保持 `pointer-events: none`，不伪装成交互控件。

## 国际化

固定前缀和每个动态词都使用现有 i18next `t()` 调用。英文及其他已支持语言提供自然的对应词语；缺少翻译时沿用现有英文回退机制。新增词条放入前端 locale 文件，并保持英文源字符串作为 key。

## 验证

- 组件测试断言默认标题包含动态词位、词库、裁剪容器和 reduced-motion 样式。
- 组件测试断言自定义标题保持静态，不挂载动态词位。
- 浏览器桌面验收确认词位存在且标题区域无布局位移；移动端确认品牌区隐藏且无横向滚动。
- 浏览器 reduced-motion 验收确认只显示静态词。
- 运行受影响 Vitest、oxlint、oxfmt、TypeScript 构建检查和 Rsbuild 生产构建。

## 不变项

- 登录、注册、OAuth、Passkey、Turnstile、ClickCaptcha、2FA、忘记密码和重置密码行为不变。
- Iconsax 视频继续使用仓库静态资源 `/assets/iconsax-sec1-new.mp4`，移动端和 reduced-motion 策略不变。
