# 公告中心与居中公告

在公告管理中创建或编辑公告，将“级别”选择为“居中弹窗”，保存为已发布状态后，登录用户会在发布时间到达后看到居中提醒。旧公告和默认、成功、警告、错误四种级别不会自动变成弹窗。

## 取消与已阅

- **取消**：仅关闭本次页面中的这条提醒；切换菜单不会立即重弹，但刷新页面或重新进入网站后仍可能出现。
- **右上角关闭、Escape、点击遮罩**：与取消相同。
- **已阅**：确认当前发布版本，同一账号在同一浏览器不再自动看到这条提醒。
- **重新提醒**：管理员更新公告发布时间并重新发布。只修改正文不会清除原有已阅记录。

已阅记录按站点和登录账号隔离，保存在本浏览器。换设备、换浏览器或清理浏览器存储后，公告可能再次出现。多条居中公告依次展示，不叠加多个遮罩。

## 回看公告

右上角公告面板展示标题、发布时间和内容摘要。点击某条公告进入完整详情页。只打开面板或查看详情，不会把居中公告自动标为已阅；用户可以在详情页明确点击“已阅”。

侧边栏原有公告入口进入公告中心，支持分类、分页和置顶排序。已阅公告仍会保留在中心。每条公告的详情地址为 `/announcements/<公告ID>`，可复制地址后再次打开。

草稿、已下架公告和未到发布时间的公告不会出现在用户列表、详情或居中提醒中；管理员仍可编辑这些记录。

## 接口兼容

`GET /api/announcements` 保持原数组响应。传入 `p` 时返回分页数据 `items`、`total`、`page` 和 `page_size`，支持 `type` 和 `level` 筛选。`GET /api/announcements/detail/:id` 返回可公开的公告详情。

本次变更使用现有公告的 `level=modal`，不增加数据库表或字段。默认 React 前端提供完整体验，classic 与独立 H5 不在本次界面改造范围内。
