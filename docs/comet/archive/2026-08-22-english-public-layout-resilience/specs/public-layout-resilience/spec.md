# Public Layout Resilience

## Purpose

公开首页和模型广场必须在多语言、明暗主题和常用桌面/平板/手机视口下保持现有视觉身份，同时允许翻译文本自然增长而不破坏布局。

## Home Hero

- Hero 保留现有标题、说明、行动入口、主题视觉背景和应用入口。
- 英文长标题和说明可以自然换行；标题行高与各内容组间距必须确保应用入口仍位于 Hero 的预期背景区域内。
- 应用入口容器及各入口允许在窄空间中收缩或换行，不得造成页面横向滚动。
- 中文布局保持当前层级和视觉节奏，不因英文适配而出现明显松散或裁切。

## Model Square

- Hero 中的标题、说明和搜索入口按真实内容高度参与文档流。
- 筛选/结果工作区不得使用会覆盖可变高度 Hero 内容的深度负边距；桌面搜索区与工作区至少保留 12px 可见间距。
- 平板和手机上的侧栏、工具栏、模型网格或列表必须保持可访问，关键容器不得产生非预期横向溢出。

## Themes And Motion

- 布局规则同时适用于 light 与 dark 主题。
- 现有装饰动画可保留；系统启用 reduced motion 时内容位置、阅读和操作不依赖动画。

## Quality Gates

- 首页与模型广场具有针对长英文文本的稳定布局回归测试，不使用完整 Tailwind class 快照。
- TypeScript 全量检查、涉及文件 lint/format、生产构建及空白错误检查必须通过。
- 浏览器验证覆盖 en/zh、light/dark 和 1910x740、1280x720、1440x900、1920x1080、768x1024、390x844。

## Release Boundary

本 change 只完成本地实现、验证和预览。在用户确认本地效果前，不提交、不推送、不合并、不部署。
