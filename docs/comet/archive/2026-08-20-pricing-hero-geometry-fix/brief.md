# Outcome

修复 `/pricing` 模型广场 Hero 右侧三张装饰卡的定位模型与桌面响应式断点，使搜索框与卡片组在 Figma 参考视口和常见窄桌面视口中保持独立、无重叠，并恢复 Figma 的卡片旋转中心、层级和可见间距。

# Scope

- 保持搜索框现有 `545x54` 参考尺寸、左侧文案位置和搜索交互不变。
- 按 Figma 节点 `75:232` 的结构，将三张卡实现为固定尺寸定位外框，卡片在外框内居中旋转，不再把旋转卡片本体直接作为定位基准。
- 在 1920px 下对齐 Figma 卡片外框坐标、卡片尺寸、角度、层级、渐变和旋转后的可见边界；搜索框右边缘与第一张卡保持约 201px 空隙。
- 调整装饰组在 1440px、1280px 和约 1230px 窄桌面视口的缩放与锚点，避免侵入搜索框、Hero 裁切异常或页面级横向滚动。
- 保持 768px 与 390px 的现有流式 Hero 行为，装饰组不阻塞内容或产生横向滚动。
- 增加保护定位外框、设计坐标和响应式缩放契约的定向回归测试，并更新 newest-first changelog。

# Non-goals

- 不修改搜索、筛选、排序、价格单位、三种视图、模型数据、详情跳转、权限或路由参数。
- 不修改工作区面板、公共导航、首页、后端、数据库、定价算法或依赖。
- 不重新设计 Figma 卡片配色，不替换已确认的三组 Figma 渐变。
- 不把装饰卡改成可交互内容，也不让它们进入键盘或辅助技术焦点顺序。
