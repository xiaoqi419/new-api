# Outcome

让忘记密码与密码重置确认页面复用登录/注册已经采用的认证体验外壳，使找回流程在视觉、主题和响应式行为上连续一致，同时完整保留已有业务流程。

# Scope

- 为共享认证体验外壳补足找回密码和重置密码的页面语义。
- 将忘记密码与密码重置确认页面接入暗色点阵背景、桌面双栏面板、主题色与紧凑表单卡片。
- 保留现有验证码、Turnstile、邮件发送、token 校验、提交、倒计时、成功与错误反馈、密码复制和返回登录行为。
- 复用已有 i18n 键并在 changelog 最新位置记录这次可见统一。
- 添加覆盖两个页面外壳、关键控件和响应式约束的聚焦回归测试。

# Non-goals

- 不改动密码找回、邮件发送或重置密码 API、请求参数、响应格式与错误处理协议。
- 不修改登录/注册欢迎文案、模型连接动画、SMTP、IP 访问策略、导航或部署配置。
- 不改变 OAuth、2FA、验证码回调及其他认证页面的布局。
- 不新增认证主题、装饰依赖或手绘图形。

# Acceptance examples

- A1：忘记密码和重置密码确认页均使用与登录/注册相同的暗色点阵认证体验外壳，桌面为双栏面板，表单区使用同一主题色、边框、阴影和紧凑密度。
- A2：忘记密码的邮箱输入、Turnstile、点击验证码、发送邮件、倒计时、成功/错误反馈保持原有行为；重置确认页的 email/token 校验、生成密码、复制、倒计时和返回登录保持原有行为。
- A3：两个页面在 320px 及以上宽度无横向滚动，表单与中文、长英文文案均不会遮挡控件；桌面品牌叙事区与移动端品牌标识保持当前认证体验的响应式规则。
- A4：找回和重置页面使用已有翻译键并在七种现有语言中可解析；本 change 不新增未翻译的用户可见文字。
- A5：其他认证回调页面仍使用其原有外壳与行为，不受此次视觉统一影响。
- A6：聚焦布局/行为测试、格式检查、受影响文件 lint、类型检查和生产构建通过。

# Constraints and invariants

- 复用现有 `AuthExperienceLayout`、`AuthCard`、`useTurnstile`、`useClickCaptcha`、`useCountdown` 与路由结构，不复制认证状态机。
- 表单区域必须保持 `min-w-0`、受限内容宽度与 `overflow-x-hidden` 的移动端约束。
- 仅修改本 child 负责的找回/重置页面、共享外壳的页面语义、相关测试、翻译使用和 changelog。
- 保留其他代理与用户已有未提交修改，不提交、合并、推送、部署或归档。

# Decisions

- 使用现有认证体验外壳而非复制一套视觉结构，确保登录、注册、找回与重置在主题和响应式策略上长期同步。
- 将找回和重置作为外壳的显式页面类型，以便保留正确的 `data-auth-page` 和可访问表单区域标签。
- 视觉变更限定在布局与卡片样式；业务处理函数、请求调用和反馈文案保持原路径。

# Open questions

- 无。

# Verification expectations

- 渲染回归测试断言两个页面的体验外壳、页面标识、关键表单控件与无横向溢出约束。
- 静态检查确认找回和重置页面不再引用旧 `AuthLayout`，且其业务 API 调用与关键控件仍存在。
- 运行聚焦测试、格式检查、受影响文件 lint、TypeScript 类型检查和前端生产构建。
