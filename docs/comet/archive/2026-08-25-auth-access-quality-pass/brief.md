# Outcome

完成认证体验与访问安全的最后一轮质量修复：使用明确的登录欢迎文案、统一忘记密码页视觉、为模型能力提示增加克制的连接动画、让 SMTP 测试邮件在网络异常时快速失败，并对中国大陆来源的官网页面请求返回主题化 HTTP 451。

# Scope

- 登录操作区默认文案调整并覆盖全部现有前端语言。
- SMTP 连接、TLS 握手和后续 SMTP I/O 使用统一绝对 deadline，测试邮件不再挂起到反向代理 504。
- 现有忘记密码/重置密码流程复用登录与注册页的认证体验外壳。
- Claude、Codex、Gemini 与更多模型提示增加克制的动态连接效果。
- 服务端根据可信地区信号阻断中国大陆来源的官网 HTML 页面请求。
- 每项用户可见变更更新 changelog，并添加与风险相称的回归测试。

# Non-goals

- 不改变登录、注册、OAuth、2FA、验证码或密码重置 API 协议。
- 不修改 SMTP 账号、端口、TLS 模式和管理员配置项含义。
- 不使用拓扑网络、大面积装饰插画或影响表单操作的动画。
- 不阻断 `/api`、`/v1`、静态资源和健康检查，不把地区未知请求误判为中国大陆。
- 不部署、推送 GitHub、切换域名或开放生产环境。

# Acceptance examples

- A1：简体中文登录页操作区第一行严格显示“欢迎回来 ！👋”，第二行严格显示“登录后进入AI的汪洋大海中~”。
- A2：英文及其余现有语言显示自然的本地化欢迎文案；长文案在 320px 宽度下不溢出。
- A3：SMTP 服务接受 TCP 后不发送 greeting、TLS 握手卡住或 STARTTLS 卡住时，邮件发送在统一 deadline 内返回可识别的阶段错误，而不是等待到网关 504。
- A4：`/api/option/test_email` 保留现有鉴权与响应契约，失败不泄露 SMTP token、账号、邮件正文或收件人。
- A5：正常的明文 SMTP、STARTTLS 和隐式 TLS 发送路径继续工作，现有 TLS 校验配置保持有效。
- A6：忘记密码与重置密码页面使用和登录/注册一致的暗色点阵背景、双栏面板、主题色和紧凑表单区。
- A7：密码找回的验证码、邮件、token、提交、成功和错误行为不变，其他认证回调页面不受影响。
- A8：忘记密码页面在桌面与 320px 手机视口无横向滚动，中文和长英文文案均不遮挡控件。
- A9：桌面认证叙事区的 Claude、Codex、Gemini 与更多模型提示之间可见克制的动态连接或流动高光，不产生布局位移。
- A10：模型连接动画不遮挡文字、不伪装成可点击控件，并跟随当前主题色而不出现旧粉色。
- A11：启用 `prefers-reduced-motion: reduce` 时动画停止或降为静态连接，信息与操作保持完整。
- A12：中国大陆来源访问官网 HTML 页面时，服务端直接返回主题化 HTTP 451 页面，登录、注册、文档和其他前端路由均不能绕过。
- A13：地区信号只接受部署环境可信来源，客户端伪造转发头或国家代码不能触发或绕过策略。
- A14：非中国大陆和地区未知请求正常放行；`/api`、`/v1`、静态资源及健康检查保持原行为。
- A15：全部新增用户可见文字进入 i18n，changelog 最新位置记录本轮变更。
- A16：前端聚焦测试、lint、format、typecheck 和生产构建通过；后端聚焦 Go 测试和 `go test ./common` 通过。
- A17：浏览器验收覆盖登录与忘记密码的桌面/手机、中文/英文和 reduced-motion；HTTP 验收覆盖 CN、非 CN、未知和伪造头场景。

# Constraints and invariants

- 遵守现有 React 19、i18next、Tailwind/Base UI 与 Go/Gin 分层，不新增仅为装饰存在的依赖。
- 邮件 deadline 必须真正作用于底层 `net.Conn` 的连接、握手与读写，不能只用不会中断 I/O 的 handler goroutine 超时。
- 地区限制必须 fail-open，且不能信任任意公网客户端直接提供的代理头。
- 生产环境继续保持当前维护与停服安排，本 change 只开发和验收代码。

# Decisions

- 五个结果拆为独立 child worktree 并行 Build/Verify，最终由 Supervisor 统一验收。
- SMTP 使用约 10 秒的共享绝对 deadline；用户可见端点必须在 15 秒内得到失败响应。
- 国内地区限制仅覆盖官网 HTML 文档请求，不影响 API 中转与后台接口协议。
- 动画使用单一连接轨道/流动高光，不使用拓扑图，并为 reduced-motion 提供静态状态。
- 用户已明确要求按推荐方案直接开发到验收，不再为实现细节重复请求确认。

# Open questions

- 无。

# Verification expectations

- Builder 分别提交聚焦测试与静态检查；每个 child 使用新的只读 Verifier。
- Supervisor 最终核对五项结果的集成行为、全部验收 ID、changelog 与无关改动隔离。
- 不以 Builder 自述或旧浏览器截图替代当前候选的独立验收证据。
