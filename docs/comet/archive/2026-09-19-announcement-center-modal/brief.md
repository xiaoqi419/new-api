# Outcome
用户能在居中弹窗阅读重要公告，并通过易发现的公告中心和独立详情页随时回看。

# Scope
公告管理级别增加“居中弹窗”；默认前端已登录区域的自动弹窗；复用 /announcements 并优化列表、分类、分页、详情页；右上角公告面板改为可点击摘要；支持桌面与手机、多语言、Markdown。不增加“查看全部公告”按钮。

# Non-goals
不改价格或渠道，不自动把旧公告设为弹窗，不发送邮件/短信，不新增跨设备已读数据库，不重做 classic 或独立 H5。此次先实现并验证，正式发布遵循 PR/CI/main 流程。

# Acceptance examples
- A1: 管理端级别增加居中弹窗，可创建、保存和重新编辑；原四种级别及旧公告保持兼容，不新增数据表或字段。
- A2: 登录用户进入应用后，仅已发布且发布时间已到的居中公告自动弹出；草稿、未来公告、下架公告不可在用户列表或详情中读取。
- A3: 弹窗参考用户截图采用宽居中面板、固定标题及底部、正文独立滚动和 Markdown，底部只有“取消”“已阅”，关闭按钮/Escape/遮罩等同取消；手机无横向溢出，多条公告使用单弹窗切换，不叠加遮罩。
- A4: 取消仅抑制本次页面生命周期的该公告，刷新/重新进入后仍提醒，当前菜单切换不立即重弹；只有“已阅”按账号、站点、公告 ID 和发布时间持久化。同浏览器不同账号不串读，重新设置发布时间后再次提醒，普通内容编辑不强制重弹。
- A5: 打开小铃铛或访问详情不自动确认居中公告；详情提供“已阅”按钮，与弹窗确认共用状态。
- A6: 保留原侧边栏公告中心入口，不新增“查看全部公告”按钮；右上角面板显示标题、时间、省略摘要，点击跳转详情。中心支持分类、置顶优先、发布时间排序及分页，已阅公告仍可查看，不静默遗漏历史公告。
- A7: 每条公告有独立详情链接，完整展示标题、分类、时间和 Markdown 正文；支持刷新、返回列表，无效或不可公开公告显示明确不可用状态。
- A8: 新文案覆盖七种语言，更新日志版本跟随构建；相关 API 权限、定时发布边界、关闭状态、导航和手机布局经独立验证通过。

# Constraints and invariants
origin/main 为生产源；独立 worktree，唯一 active change。复用现有公告表和 Markdown 组件；保护草稿，不修改旧公告数据。无订阅、收费、渠道配置变更。

# Decisions
用户明确要求在公告管理级别增加居中显示选项，新增便于回看的公告中心及详情。调查确认已有基础 /announcements 页面、侧边栏入口及公开详情 API，应完善入口可见性与详情体验，不重复建设。
用户已确认修订方案：新增 level=modal，默认不选；不增加查看全部入口；取消下次再提醒，已阅才持久化；详情访问不自动已阅但提供已阅操作。参考截图宽面板并跟随站点主题。
该需求在展示、导航、已读状态方面高度关联，保持单 change，不拆 Supervisor Change。

# Open questions
无。用户回复“可以的”明确确认修订后的行为。

# Verification expectations
独立只读 Verifier 按 A1–A8 验证；Go 测试公开列表/详情可见性及 level 保存；前端行为测试关闭与账号隔离、入口和详情；typecheck/build/i18n、桌面和手机浏览器检查。
