# Outcome

将登录后的导航图标统一替换为 `lucide-react` 开源图标，移除认证态导航对 New API 现有图标适配层的依赖，在不改变信息架构和业务行为的前提下获得一致、清晰、可维护的图标语言。

# Scope

- 替换认证后主侧栏及其移动端形态中的全部栏目图标。
- 替换账户中心、财务中心、用量日志、系统设置等嵌套侧栏视图中的导航图标。
- 让命令菜单复用替换后的导航图标，并将顶部导航图标解析改为直接使用 Lucide 图标集合。
- 让模型广场、模型详情和排行榜的公开路由守卫与公共顶部导航共享同一份刷新后的状态快照，避免切换时短暂回闪旧导航。
- 从认证侧栏移除“AI 媒体”分组及“素材库”“无限画布”“成为代理”入口，避免这些已决定屏蔽的入口随图标替换重新出现。
- 保持现有图标尺寸、颜色语义、折叠态、选中态、悬停态和 tooltip 行为。
- 增加聚焦回归测试，并在 changelog 记录本次可见变化。

# Non-goals

- 不替换站点 Logo、模型/供应商品牌 Logo、支付品牌或 OAuth 品牌图标。
- 不批量替换页面内容区、表格操作、按钮、状态提示等非导航用途图标。
- 除明确屏蔽的“AI 媒体”和“成为代理”入口外，不改变其他导航路由、顺序、分组、文案、权限、后台显隐配置或点击行为；底层页面和 API 不在本次删除范围内。
- 不新增图标依赖；使用项目已安装的 `lucide-react`。
- 不提交、合并、推送或部署，直至用户验收候选界面。

# Acceptance examples

- A1：登录后桌面主侧栏和移动侧栏中，“AI 媒体”分组及“素材库”“无限画布”“成为代理”入口均不可见；其余导航项目继续使用来自 `lucide-react` 的图标，路由、顺序、分组和权限过滤保持一致。
- A2：账户中心、财务中心、用量日志与系统设置等嵌套导航使用同一 Lucide 图标语言，进入和返回嵌套视图的行为不变。
- A3：命令菜单显示与对应侧栏一致的 Lucide 图标；认证态顶部导航中已配置的图标名称仍可解析，未知或显式为空的配置继续安全降级。
- A4：认证导航定义不再从 `@/components/icons` 获取栏目图标；品牌、模型与 OAuth 图标不受影响。
- A5：侧栏展开、折叠、移动抽屉和长英文文案下，图标尺寸稳定、与标签对齐，无遮挡、变形或横向溢出。
- A6：后台侧栏模块与顶部导航配置仍按原有状态字段生效；明确屏蔽的入口不会因角色或配置重新出现，其余可见性和可访问路由不变。
- A7：聚焦测试、静态检查、类型检查与生产构建通过，浏览器至少验证普通用户和管理员导航的桌面与手机形态。
- A8：从任意页面进入模型广场、模型详情或排行榜时，公共顶部导航直接使用路由守卫刚刷新到的状态；页面不得短暂显示旧版或原始导航，最终模块可见性仍以后台配置为准。

# Constraints and invariants

- 遵守现有 React 19、TypeScript、Tailwind、TanStack Router 与导航数据结构。
- 直接复用 `lucide-react` 导出的图标组件和 `LucideIcon` 类型，避免创建新的 SVG 或重复图标适配层。
- 保留现有 `NavGroup`、`NavItem`、sidebar registry、模块过滤和路由匹配逻辑。
- 保留用户及其他代理已有改动；本 change 在独立 worktree 中实现。

# Decisions

- 采用 `lucide-react` 作为认证态导航的唯一通用图标来源。
- 替换范围以“承担导航含义的图标”为边界，不扩大到功能按钮和内容视觉。
- 图标名称选择遵循语义优先，避免只为外观不同而使用含义不清的符号。
- 顶部导航继续支持后台保存的现有 Lucide 风格名称；缺省映射保持 Home、Gauge、Boxes、Trophy、FileText、BookOpen、Info、Users。
- 公开受模块配置约束的路由使用同一份状态查询缓存刷新结果驱动公共顶部导航，避免路由守卫和 Header 在一次跳转内读取不同快照。
- “AI 媒体”分组和“成为代理”仅从认证侧栏信息架构中隐藏，不删除对应页面实现或后端能力。

# Verification expectations

- 使用 `rg` 检查全部认证导航定义及旧适配层引用残留。
- 运行导航数据/解析相关聚焦测试、lint、格式检查、类型检查和生产构建。
- 在普通用户与管理员角色下检查桌面侧栏、折叠态、移动抽屉、嵌套导航和命令菜单。
- 独立只读 Verifier 逐项验收 A1-A7。
