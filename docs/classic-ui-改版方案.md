# Classic UI 改版方案（含全站 UI 草图）

> 目标：在现有 **web/classic**（Semi Design + rsbuild）内，把 UI 做得更简洁好看，并重新组织信息架构 / 模块布局。
> 不迁移主题、不改后端、不改架构，仅改视觉（CSS token + 组件样式）与布局组织。
> 参考：wxiai（极简开发者风）、coultra/GPTMeta（营销落地风）、gpt.ge / V-API（极简黑白）。
>
> **本文件为方案 + 线框草图，不含代码改动。**
> 品牌保护：QuantumNous / new-api 的所有标识、版权头、元数据必须原样保留。

## 0. 已拍板决策（2026-07-09）

| 项 | 决策 |
|---|---|
| 范围 | 在 classic 内重做视觉 + 重组信息架构（架构/技术栈不变） |

## 1. 全站设计规范（Design Tokens）

> 落点：`web/classic/src/index.css` 的 token 层（`:root`、`data-ui-preset='apimart'`、以及 `--semi-color-*` 覆盖）。默认预设为 apimart（浅色 + 竖向侧边栏）。

### 1.1 颜色

| Token | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| primary | `#7c5cff` | `#a78bfa` | 主色（按钮/链接/强调/激活态） |
| primary-hover | `#6a46f0` | `#b9a2ff` | 悬停 |
| primary-light | `rgba(124,92,255,.08/.14)` | 同比 | 浅底/选中底 |
| bg（画布） | `#f7f7fa` | `#0b0d10` | 页面背景 |
| surface（卡片） | `#ffffff` | `#14171c` | 卡片/面板 |
| border | `rgba(15,23,42,.08)` | `rgba(255,255,255,.08)` | 弱化边框 |
| text / secondary / muted | `#0f172a / #475569 / #94a3b8` | 反相 | 三级文字 |

规则：**只保留一个主色**；移除首页/定价的渐变、星空、彩虹统计色，改为「中性 + 主色点缀」。

### 1.2 圆角 / 阴影 / 动效

```
--app-radius-sm: 8px      小元素（tag/输入/小按钮）
--app-radius:    10px     卡片/按钮基准
--app-radius-lg: 12px     面板/弹窗
--app-radius-xl: 16px     大容器/hero 卡

--app-shadow-sm: 0 1px 2px rgba(16,24,40,.04)          卡片静止
--app-shadow-md: 0 4px 16px rgba(16,24,40,.06)         卡片悬停
--app-shadow-lg: 0 16px 40px rgba(16,24,40,.08)        弹窗/浮层

--app-ease: cubic-bezier(.16,1,.3,1)
hover：transform: translateY(-2px) + shadow-md，150ms
```

### 1.3 间距节奏

```
4 / 8 / 12 / 16 / 24 / 32 / 48   （8 的倍数为主）
区块纵向间距 48–64；卡片内边距 20–24；网格 gap 16–20
```

### 1.4 字体

```
正文：Lato / 系统无衬线（沿用）
模型名 / 代码 / API Base：等宽字体（ui-monospace, SFMono, Menlo）
标题字号加大、字重 600–700，行距放宽
```

## 4. 组件级统一规则（P5 打磨清单）

- **卡片**：surface 底 + 10px 圆角 + shadow-sm，hover 上浮 + shadow-md
- **按钮**：主按钮实心主色；次按钮描边；危险操作红；统一高度/圆角
- **输入/选择**：8px 圆角，聚焦主色描边
- **Tag/徽章**：小圆角，弱底色，分类色克制
- **表格**：行高统一、斑马纹去除或极弱、表头浅底、操作列图标化
- **弹窗/抽屉**：lg 圆角 + shadow-lg，头部标题层级统一
- **空态/加载**：统一骨架屏 + 空状态插画/文案
- **模型名/代码/Key**：等宽字体
- **图标**：统一一套线性图标，弱化多彩

## 5. 分批执行计划（低风险，可回退）

每批：改完 → 构建通过 → 浏览器逐页截图核对 → 你确认 → 下一批。全程 classic 架构不变、后端零改动、可随时回退。

## 6. 风险与注意

- **默认预设 = apimart**：token 改动需覆盖 `data-ui-preset='apimart'` 的明/暗两态。
- **P4 导航重组**风险最高：涉及 `SidebarModulesAdmin` / 用户 `sidebar_modules` 的模块开关与权限，需保证管理员/普通用户可见性正确，逐项回归。
- **品牌保护**：首页/页脚/关于页的 QuantumNous / new-api 标识与版权头一律保留。
- **不做**：不迁移 default 主题、不改后端、不改技术栈（Semi Design 保留）。
- 现有的 APIMART 定制 CSS（约 3800 行）在 P1–P5 中逐步收敛为统一规范，不推倒重来。
